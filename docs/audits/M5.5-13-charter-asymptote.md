---

## The rulings

- **A charter is an asymptote.** It describes the set's ideal end state, independent of the current population, and the population is measured against it.
- **The charter states end state, scope and growth policy.** Purpose opens with the end state. Territory states scope and a growth policy - capped or uncapped, the altitude a member sits at, what members are balanced on.
- **Partitions and gaps belong to investigations.** A territory can be cut in several defensible ways, and missing dimensions cannot be listed before investigation. An investigation is a dated analysis; a later one may cut the set differently without the charter changing.
- **Gaps become backlog rows; the board weighs them.** A charter does not rank its own gaps.
- **A charter does not name its members.** Only the generated index lists them; a set spanning layers declares its members in a `members` list.

## What changed

| Where | Change |
|---|---|
| `E4` | the asymptote paragraph replaces *a charter holds the set's vision*; Purpose asks for the end state first; Territory asks for scope and growth policy; *what a territory states* replaces *a territory must earn itself*, kept under a correction banner; a *re-aim* row in the change table for a change to end state, scope or growth policy, director-ratified |
| `E3` | a set states its end state, scope and growth policy; completeness is judged by investigation against them |
| sixteen charters | each Purpose opens with an end state; each Territory states scope and growth policy only; partitions, placements and gaps moved verbatim to `docs/investigations/<set>-2026-10-04.md`; members no longer named outside the index |
| backlog, board | one held row per investigation, `B55`-`B69`, carrying its gaps with each gap's trigger in the investigation |
| `tools/generate-index.mjs` | the axioms index shows each axiom's `applies-to`, replacing the charter's hand matrix |
| `tools/eval.mjs` | export keeps `docs/investigations/`, which charters link to and which holds no key |
| `docs/ARCHITECTURE.md` | components are units, not substrates |

Terms were chosen to avoid collisions found in review: *growth policy*, not *composition policy*, beside `E4`'s Composition concern; *capped* and *uncapped*, not *bounded* and *open*, beside `E3`'s *bounded population*.
