### 1.1 Corrected - the declinability sentence

| | |
|---|---|
| **Old** | *Named procedures for conducting work, each one declinable in a given situation and none of them optional once you are in the situation it names.* |
| **New** | *Named procedures for conducting work, each applying only in the situation it names and binding once you are in it.* |
| **Plus** | *A procedure is declined by not being in its situation, never by deciding it does not apply once you are.* |
| **Kind** | correct |

**Why.**\
The old sentence was ambiguous rather than wrong, and the ambiguity produced a false finding.\
"Declinable in a given situation" reads naturally as *declinable once in the situation*, which is the opposite of what the second half says.\
The trial read it that way and recorded a tension with `M7`, which calls itself a required gate.

**The tension was a misreading, and this edit is what removes it.**\
`M7` has an explicit trigger list - *"Run an axiom alignment audit when any of these are true"* - and an explicit exclusion - *"A short local bugfix does not require a standalone audit."*\
It is declinable outside its situation and mandatory inside it, which is exactly what this charter means.\
"Required gate" means required once triggered.\
The trial could only flag the conflict, because the verbatim rule forbade fixing the sentence that caused it.

**Cost against quality.**\
A charter's opening sentence is its most-read sentence, so editing it carries the highest cost of any line. ~~It is paid for: the old wording generated a false finding in a careful reader, and would again.~~

**Corrected by the semantic evaluation in section 7.**\
The claim was that the old sentence *misleads*.\
Three fresh agents given only the old charter all answered the trap question correctly - none was misled.\
All three did flag the sentence as ambiguous and reasoned around it, and one hedged its conclusion.\
So the false finding was this reviewer's, not a property of the sentence.\
The edit is still paid for, on a smaller claim: it removes an ambiguity careful readers notice and must work around, so that the answer is stated rather than reconstructed.

### 1.2 Reworded - layer to set

| | |
|---|---|
| **Old** | *The layer boundary is the object the rule acts on.* |
| **New** | *The boundary of this set is the object the rule acts on.* |
| **Kind** | reword |

**Why.**\
[`E3`](../../entities/E3-set.md) now separates *layer* - a directory - from *set* - a population with a charter.\
A boundary is a property of the population, so the old word was imprecise under the corpus's current vocabulary.

**Cost against quality.**\
Low cost, small gain.\
Made because the neighbour table beneath it is the corpus exemplar for set boundaries, and its introducing sentence should use the term the table exemplifies.

## 7. Semantic evaluation

The verdict above was first reached by the author reading both versions - an instrument reporting on itself.\
It was then tested by fresh agents holding only one blinded version each, against a key written before any ran.

| | Original | Candidate |
|---|---|---|
| Mean score, six probes, three runs each | **8.67 / 12** | **12.0 / 12** |
| Control probes the original already answered (P1, P5) | 6 / 6 | 6 / 6 |
| Selection, gap and relation probes (P2-P4) | 3 / 6 per run | 6 / 6 per run |
| Agents answering from the document rather than guessing | 2-3 of 6 probes | 6 of 6 |

**Confirmed.**\
The territory and composition additions do the work claimed.\
Every original-charter agent said the document did not answer the handover, gap and relation questions and fell back on guessing; every candidate agent answered them from quoted text.

**Not damaged.**\
The control probes scored identically.

**Contradicted.**\
The correction to the opening sentence was claimed to fix a sentence that misleads.\
It does not mislead: all three original-charter agents answered the trap correctly.\
It was ambiguous, and they said so.\
The audit's claim is corrected above.

**Found, that nobody had seen.**\
All three original-charter agents independently flagged that `M7`'s trigger - *you are judging whether a design decision is anchored to a first principle* - is narrower than its title - *required gate for extensive planning/design*.\
That is a real defect in `M7`, outside this charter, and is recorded in the backlog.\
Candidate-charter agents did not raise it, which is worth noting: the clearer charter suppressed a question that was worth asking.

Full probes, key, blinded charters and per-run scores are retained beside this file.
