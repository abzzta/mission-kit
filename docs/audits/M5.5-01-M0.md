### 1.1 Corrected - the declinability sentence

| | |
|---|---|
| **Old** | *Named procedures for conducting work, each one declinable in a given situation and none of them optional once you are in the situation it names.* |
| **New** | *Named procedures for conducting work, each applying only in the situation it names and binding once you are in it.* |
| **Plus** | *A procedure is declined by not being in its situation, never by deciding it does not apply once you are.* |
| **Kind** | correct |

**Why.**\
The old sentence was ambiguous rather than wrong, and the ambiguity produced a false finding.\
"Declinable in a given situation" reads naturally as *declinable once in the situation*, which is the opposite of what the second half says.\
The trial read it that way and recorded a tension with `M7`, which calls itself a required gate.

**The tension was a misreading, and this edit is what removes it.**\
`M7` has an explicit trigger list - *"Run an axiom alignment audit when any of these are true"* - and an explicit exclusion - *"A short local bugfix does not require a standalone audit."*\
It is declinable outside its situation and mandatory inside it, which is exactly what this charter means.\
"Required gate" means required once triggered.\
The trial could only flag the conflict, because the verbatim rule forbade fixing the sentence that caused it.

**Cost against quality.**\
A charter's opening sentence is its most-read sentence, so editing it carries the highest cost of any line.\
It is paid for: the old wording generated a false finding in a careful reader, and would again.

### 1.2 Reworded - layer to set

| | |
|---|---|
| **Old** | *The layer boundary is the object the rule acts on.* |
| **New** | *The boundary of this set is the object the rule acts on.* |
| **Kind** | reword |

**Why.**\
[`E3`](../../entities/E3-set.md) now separates *layer* - a directory - from *set* - a population with a charter.\
A boundary is a property of the population, so the old word was imprecise under the corpus's current vocabulary.

**Cost against quality.**\
Low cost, small gain.\
Made because the neighbour table beneath it is the corpus exemplar for set boundaries, and its introducing sentence should use the term the table exemplifies.
