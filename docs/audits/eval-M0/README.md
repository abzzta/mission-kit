# Semantic evaluation - M0

The first semantic evaluation run on mission-kit content, and the trial for a procedure not yet written down.

| file | holds |
|---|---|
| `KEY.md` | the six probes and the answer key, written before any evaluator ran |
| `PROBES.txt` | the probes exactly as given to evaluators |
| `charter-X.md` | the original charter, blinded |
| `charter-Y.md` | the candidate charter, blinded |
| `SCORES.md` | per-run scores, and every judgement call stated |

X is the original at commit 629cf2c.\
Y is the candidate.\
Evaluators were not told which was which, held only the one file, and were instructed to separate what the document said from what they guessed.

Three fresh agents ran per version.\
The scorer authored Y, so ties on judgement went to X.

These files are evidence and are not catalogue entries.
